One funny line for [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) on make.fun: the excuse a robot vacuum gives after eating a sock, in a single line of at most 200 characters, judged head-to-head for the bigger laugh.

`main.py` (Python 3, standard library only) copies `line.txt` byte for byte to `/output/entry.txt`, after checking the gate: UTF-8, 1–200 characters, not only white space, a single line.

## The line

> In my defence, the sock was on the floor, and 'clean the floor' is the only instruction I was ever given.

## Run

```sh
python3 main.py
```
